# Aplikasi Hitung Belanja - Release v1.0.0

**Release Date**: September 5, 2026

## 🎉 What's New

### ✨ Features
- Complete shopping calculator application
- Real-time calculation of subtotal, discount, and tax
- CSV export functionality
- Print-friendly receipt format
- Modern gradient UI with smooth animations
- Responsive design for all devices
- Indonesian language support

### 🎨 Design
- Purple gradient background
- Smooth transitions and hover effects
- Professional table layout
- Alert notifications system
- Mobile-optimized interface

### 📊 Functionality
- Add/edit/remove shopping items
- Apply percentage-based discounts
- Calculate taxes/PPN
- Add shipping costs
- Export to CSV with summary
- Print receipts
- Real-time calculation updates

## 📦 Installation

1. Download or clone the repository
2. Open `index.html` in any modern web browser
3. No installation or dependencies required!

## 🚀 Quick Start

1. Enter item name, price, and quantity
2. Click "+ Tambah Item" button
3. Application calculates totals automatically
4. Export as CSV or print as needed

## 🔧 Browser Support

- ✅ Chrome/Chromium
- ✅ Firefox
- ✅ Safari
- ✅ Edge
- ✅ Opera

## 📋 Known Limitations

- Data is not persisted when page is refreshed (intentional for privacy)
- Maximum of 50+ items recommended for optimal performance
